**Проект по автоматическому извлечению предмета сделки из текстов договорных документов с использованием multi-label классификации**

## 📋 О проекте

Цель проекта — разработка системы для автоматического извлечения предмета сделки (оказываемых услуг) из договорных документов с помощью методов машинного обучения.

### 🎯 Основные задачи

- **Разметка данных** с использованием Large Language Models (LLM)
- **Дообучение энкодерных моделей** для multi-label классификации текстов
- **Разработка сервиса** для автоматического определения услуг по тексту документа

## 🚀 Функциональность

- **📊 Автоматическая разметка** данных с помощью LLM
- **🤖 Multi-label классификация** текстов договоров
- **🔍 Извлечение услуг** из документов
- **🌐 REST API сервис** для интеграции

## 🛠 Технологии

- **Python** — основной язык разработки
